# OPEN FEED web docs (GitHub Pages)

Static site for the game design document, dev diary, and presentation mode.

## GitHub Pages setup

1. Repo **Settings → Pages**
2. **Build and deployment → Branch:** `Presentation`
3. **Folder:** `/docs`
4. Save

Site URL (project pages): `https://martinorav-png.github.io/open-feed/`

Entry points:

- [index.html](index.html) — hub
- [GDD_ACADEMIC.html](GDD_ACADEMIC.html) — design doc + **Esitlus**
- [OPEN_FEED_Devlog_browse.html](OPEN_FEED_Devlog_browse.html) — dev diary
